----------------------------------------------------------
PROJECT OVERVIEW
----------------------------------------------------------

CarCare is a modern mobile application UI/UX design
created using Figma for professional car wash and
vehicle maintenance services.

The application enables users to browse available
services, schedule appointments, confirm bookings,
and track service progress through a clean and
user-friendly interface.
