## 📌 Project Overview

CarCare is a mobile application UI/UX design created in **Figma** for professional car wash and vehicle maintenance services.

The application allows users to:

- Register and Login
- Browse available car care services
- Select preferred service packages
- Schedule appointments
- Choose date and time slots
- Track service progress
- Receive booking confirmation
